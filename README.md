# 狭山茶の平塚園 リニューアル（プロトタイプ）

https://www.hiratsukaen.co.jp/ のリニューアル案です。伊藤園（itoen.jp）の UI/UX を基調に、一保堂茶舗・中村藤吉本店・福寿園の良い点を取り入れて作っています。決済・フォーム送信は実装していません。

## 起動方法

```bash
npm install      # 初回のみ
npm run dev      # → http://127.0.0.1:4321 （Astro 7 はバックグラウンドで起動します）
npx astro dev stop   # 開発サーバーを止める
npm run build    # dist/ に静的HTMLを書き出し
npm run preview  # 書き出したサイトを確認
```

## 確認用サイト（GitHub Pages）

- URL：https://tokuyamazaki-stack.github.io/hiratsukaen-site/
- `main` ブランチに push すると、GitHub Actions（`.github/workflows/deploy.yml`）が自動でビルドして公開します（1〜2分）。
- 確認用ビルド（`PUBLIC_PREVIEW=true`）では、検索エンジンに載せない設定（noindex）と、画面上部の「リニューアル確認用サイト」表示が付きます。
- サブフォルダ（`/hiratsukaen-site/`）で公開するため、ビルド時に `BASE_PATH` を渡しています。HTMLに書いた `/products/` などのリンクは `integrations/base-path.mjs` が自動で補正します。JSやJSONでURLを組み立てるときは `src/lib/url.ts` の `withBase()` を使ってください。
- 本番ドメイン（www.hiratsukaen.co.jp）で公開するときは、`PUBLIC_PREVIEW` と `BASE_PATH` を指定せずにビルドします。

## 伊藤園から取り入れた主なUI

- 太字のグローバルナビ＋メガメニュー、右端の検索アイコン、小さなユーティリティリンク
- メインビジュアル下の「‹ ❙❙ • • • ›」コントロール、1行のお知らせ帯
- 縦書き見出しのブランドコンセプト・スライダー（次の画像が右端に覗くレイアウト）
- 緑の縦バー見出し、縦書きの「ピックアップ」＋タブ、枠付き商品カード
- 右端まで伸びる薄緑パネルの「商品を探す」（キーワード／カテゴリ／アイコン付きサブカテゴリ）
- キャンペーン風の一覧（贈り物）、3カラムカード（店舗・ご注文）、2カラムのトピックス
- 大きなグレーのリンクボタン、右下の「どのような情報をお探しですか？」パネル

他社から：一保堂（送料無料のお知らせバー、カテゴリアイコン）、中村藤吉（売れ筋の順位表示、電話・FAX注文の明示）、福寿園（銘柄シリーズの見せ方）。

## データと素材

- 商品データ：`src/data/products.json`（現行サイトの全50商品の名前・規格・価格・説明・画像）
- 会社・店舗・カテゴリ・お知らせ・いれ方の目安：`src/data/site.ts`
- 商品画像：`public/images/products/`（現行サイトから取得）
- 茶畑・お茶の写真：`public/images/photo/`（Wikimedia Commons。ライセンスは `/credits/` に記載）
- カートは `localStorage` に保存するだけのデモです。「ご購入手続きへ」は説明モーダルを表示します。

## 公開前に確認・差し替えが必要なもの

- [ ] **お知らせ**：`src/data/site.ts` の `news` はデザイン確認用のサンプル（日付・内容とも）

- [ ] **お問い合わせフォーム**：送信先（メール送信サービス等）の決定
- [ ] プライバシーポリシーはカラーミーショップ利用前提の文面のまま。カートを変える場合は要修正
